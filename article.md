# article.md — Envíos DosRuedas: Plataforma Logística y Sistema de Diseño (Mar del Plata)

## Resumen del Proyecto y Contexto
Envíos DosRuedas es el sistema de diseño integral y la plataforma web de alta velocidad que agrupa 19 landing pages especializadas en servicios logísticos en Mar del Plata, Argentina. Creado en noviembre de 2026, combina una identidad visual vibrante de alto impacto urbano —bicolor eléctrico y amarillo acento— con un rendimiento optimizado mediante HTML5 semántico y CSS moderno, ofreciendo soluciones a medida para envíos exprés, lowcost, entregas Flex de Mercado Libre, cuentas corrientes corporativas, fulfillment 3PL, contrareembolso y planes para emprendedores.

## Highlights Técnicos y de Diseño
- **Bicolor Oficial**: Azul eléctrico (`#0950F6`) y Amarillo acento (`#FFEC01`) para máxima visibilidad urbana y de marca.
- **Tipografía de Vanguardia**: Anton para titulares impactantes, Bebas Neue para píldoras y subheadings, Outfit para lectura fluida y Geist Mono para métricas y precios.
- **Ecosistema de 19 Landing Pages**: Cero dependencias pesadas de frameworks, rendimiento nativo instantáneo, interactividad accesible con menú drawer, dropdowns y navegación optimizada para conversión directa vía WhatsApp.
- **Infraestructura de Documentación**: Generador automatizado integrado (`generate_repo_guide.js`) que mantiene la guía técnica (`docs/GUIA_DEL_REPOSITORIO.md`) y la versión ejecutable imprimible (`docs/guia_del_repositorio.html`) siempre sincronizadas.
